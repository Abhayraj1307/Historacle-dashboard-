# Historacle.ai Launch Intelligence Platform

## AI-Powered BI&A Decision-Support System for Content Strategy

An AI-powered Business Intelligence & Analytics platform developed to support Historacle.ai’s launch, audience growth, and content optimization strategy.

This project combines predictive analytics, clustering, statistical validation, AI-assisted content generation, and strategic intelligence into a unified decision-support system for modern content ecosystems.

---

# Executive Overview

Modern content creation still relies heavily on trial-and-error.

Creators and brands often struggle with:
- unpredictable engagement
- inconsistent performance
- lack of strategic visibility
- reactive decision-making
- inefficient experimentation

The Historacle.ai Launch Intelligence Platform was developed to transform content strategy from guesswork into data-driven intelligence.

The system analyzes social media engagement patterns, predicts viral potential, identifies strategic opportunities, and generates AI-assisted optimization recommendations.

Rather than functioning as a traditional dashboard, the platform evolved into a predictive intelligence and strategic decision-support system.

# How to Run the Project

## 1. Clone Repository

```bash
git clone https://github.com/Abhayraj1307/Historacle-dashboard-.git
```

---

## 2. Navigate to Project Folder

```bash
cd Historacle-dashboard-
```

---

## 3. Create Virtual Environment (Recommended)

```bash
python3 -m venv venv
```

---

## 4. Activate Virtual Environment

### Mac/Linux

```bash
source venv/bin/activate
```

### Windows

```bash
venv\\Scripts\\activate
```

---

## 5. Install Dependencies

```bash
pip3 install -r requirements.txt
```

---

## 6. Run Streamlit Application

```bash
streamlit run app.py
```

If Streamlit command does not work:

```bash
python3 -m streamlit run app.py
```

---

## 7. Open in Browser

After running successfully:

```text
Local URL: http://localhost:8501
```

Open the URL in your browser to access the dashboard.
